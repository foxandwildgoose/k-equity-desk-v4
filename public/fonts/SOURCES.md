# Bundled application fonts

These unchanged upstream WOFF2 files are served from the application origin.
Both font families use the SIL Open Font License 1.1; the complete licenses are
included alongside the files. No external stylesheet is required for rendering.

- Pretendard Variable 1.3.9: https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard/dist/web/variable/woff2
  (`Pretendard-LICENSE.txt`).
- IBM Plex Mono, regular/medium/semibold: https://github.com/IBM/plex/tree/master/packages/plex-mono/fonts/complete/woff2
  (`IBMPlex-LICENSE.txt`).

Downloaded from the upstream repositories on 2026-10-23 (Asia/Seoul).
