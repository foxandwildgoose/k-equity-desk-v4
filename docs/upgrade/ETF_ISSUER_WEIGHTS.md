# ETF 운용사 공시 비중과 상품 링크

## SOL 글로벌DRAM반도체플러스 (0246X0) 오류

기존 `getEtfBundle`은 공식 비중이 없으면 `fillLiveMarketWeights`에서 편입 수량 × 조회 가격을 계산하고 전체를 100%로 환산했습니다. 동시에 `fetchWorldQuotes`는 원화가 아닌 해외 통화를 모두 USD로 처리했습니다. 일본 상장 키옥시아(285A.T)의 엔화 가격도 달러로 취급되어 원/달러 환산이 적용될 수 있었습니다. 따라서 화면의 시가 비중은 운용사 공시 NAV 비중과 다르며, 키옥시아 86.12%는 신뢰할 수 있는 공시 비중이 아닙니다.

사용자 첨부 XLS의 기준일은 **2026-10-08**입니다. 주요 비중은 삼성전자 25.23%, 마이크론 24.51%, SK하이닉스 24.45%, 키옥시아 3.89%이며, 현금성자산 1.20%까지 11행의 합계가 100.00%입니다. `CASH00000001 / 100%현금설정액`은 설정단위 총액 486,297,518원이며 편입 종목이 아닙니다.

원본은 `artifacts/etf-issuer/sol-dram-0246X0-20261008.xls`에 보관합니다. SHA-256은 `8181d3c7bf15076729cf0293acc7bb0fc7b447e02dd5fbb12a60610e58a9b730`입니다. 날짜와 원본 파일 정보가 있는 스냅샷은 해당 코드에만 적용되며, 최신 조회로 표시하지 않습니다.

## 표시 정책

- 비중은 운용사 공시의 비중 열에서 읽습니다. 시세·수량·환율로 비중을 만들거나 합계 100%로 재조정하지 않습니다.
- 네이버·WiseReport는 시세 및 참고 종목명에 사용할 수 있지만, 비중의 근거로 승격하지 않습니다.
- 기준일이 다른 자료는 혼합하지 않습니다. 검증 가능한 운용사 자료 중 최근 기준일을 우선하며, 조회 실패 시 해당 ETF의 명시적으로 날짜가 있는 첨부 자료를 사용할 수 있습니다.
- 전체 공시 확인이 불가능하거나 비중이 빠진 경우 `—`를 표시합니다. 부분 구성표를 전체 펀드 비중으로 간주하지 않습니다.
- 가격은 실제 통화로 표시합니다. 일본 주식을 USD로 처리하지 않으며, 통화를 확인하지 못한 경우 이를 명시합니다.
- 운용사 상품 링크는 ETF 코드와 운용사 펀드 식별자를 대조합니다. 검색 결과나 홈페이지를 상품 상세 주소로 표시하지 않습니다. 확인 실패는 버튼에 별도로 표시합니다.

## 조회와 검증

기존 KODEX·IBK·PLUS·HANARO 공식 공시 어댑터에 SOL·TIGER·ACE·KIWOOM·KoAct·RISE 조회를 연결했습니다. SOL은 `/api/etf/pds`의 `ETF_CD6`와 `FUND_CD`를 연결하고 `/api/etf/pds/pdf/{FUND_CD}`의 `WT_DISP`를 읽습니다. RISE는 상위 30종목 JSON 대신 KB자산운용의 날짜별 전체 XLSX 다운로드에서 공시 비중 열을 읽으며, 실제 현금과 채권을 보존합니다. 상품 주소 탐색은 브랜드 변경 별칭을 포함한 19개 운용사 계열을 인식합니다.

그 외 운용사는 확인된 공식 상품 페이지에 날짜와 전체 공시 비중 표가 있는 경우에만 공통 파서로 읽습니다. TIME 등 일부 운용사의 별도 바이너리 XLS 다운로드는 전용 어댑터가 아직 없어, 공식 페이지에 검증 가능한 전체 표가 없다면 비중을 표시하지 않습니다. 모든 운용사의 실제 API 접속과 모든 상품 링크가 검증되었다는 의미는 아닙니다.

외부 응답 지연도 제한합니다. 첨부 자료의 ETF 식별자는 외부 검색 없이 확보하고, 시세 메타데이터와 참고 구성표는 병렬로 조회합니다. 운용사 조회는 단계당 최대 10초, 선택적인 종목 검색은 전체 1.5초, 편입 시세 조회는 2초로 제한하여 외부 사이트 장애가 공시 비중 표시를 계속 막지 않도록 합니다. 실제 지연을 재현하는 파이프라인 테스트도 포함했습니다.

공식 사이트의 카탈로그와 API는 변경될 수 있으므로 런타임의 종목코드·날짜·비중 검증이 필요합니다. 이번 환경에서는 운용사 사이트 요청이 프록시의 `403 Domain forbidden`으로 차단되어, 환경 설정 초안에 필요한 도메인을 추가했습니다. 이 초안 저장만으로 현재 실행 환경의 접속 허용이 적용되지는 않습니다. 환경 설정에서 네트워크 변경을 저장한 후 실제 최신 공시와 상품 페이지를 재검증해야 합니다.

`npm run test:etf`는 운용사 비중 선택·첨부 자료·통화·상품 식별·구성표 파싱을 검사합니다. `npm run qa:etf-issuer`는 첨부 비중과 분리된 테스트용 시세·링크를 사용하여 데스크톱/모바일 화면을 검증하며, 실제 공식 사이트의 최신 데이터 조회 검증을 대체하지 않습니다.

이번 수정의 ETF 회귀 테스트 96개, 지연을 재현한 실제 서버 파이프라인 테스트, 타입 검사, 프로덕션 빌드가 통과했습니다. 개발과 프로덕션 각각 12가지 화면 검증에서 비중·출처·상품 버튼·확인 불가 상태를 확인했습니다. 외부 응답을 가로채지 않은 실제 개발/프로덕션 SOL 화면에서도 첨부 공시 11개 비중과 합계 100%가 표시되었습니다. 이는 첨부된 과거 공시의 표시 검증이며 최신 운용사 조회 성공을 뜻하지 않습니다. 기본 브라우저 검사는 두 화면 크기에서 렌더링과 개발/프로덕션 일치를 확인했으나, 기존 외부 폰트·스크립트의 네트워크/인증서 오류로 실패 상태를 기록했습니다. 페이지 실행 오류와 가로 넘침은 없었습니다.

이 변경은 저장소 소스의 수정입니다. Vercel 운영 배포 또는 환경 게시를 수행했다는 의미가 아닙니다.
